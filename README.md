# 🌍 THE EXPLORER

<p align="center">
  <img src="https://github.com/Abhranil2004/The-Explorer/blob/general/Logo.png" alt="The Explorer Banner"/>

**The Explorer** is a thrilling Unity-powered 3D adventure game where you journey through an alien world filled with mystery, vibrant landscapes, and hidden secrets. 🌌🧭

> 🔥 Currently Available Levels: **Level 1** and **Level 2**  
> 🛠️ **More levels coming soon!** Stay tuned for exciting new adventures...

---

## 🎮 Game Features

- 🚀 Immersive 3D world with rich, colorful visuals
- 🧠 Puzzle-solving and exploration mechanics
- 🔋 Futuristic character design and interactive environment
- 🎯 Easy to play, hard to master
- 🗺️ Upcoming levels with increasing difficulty and storytelling

## 📂 How to Play

1. Download the latest release from the [The Explorer(Download)](https://the-explorerr.netlify.app/) section.
2. Extract the `.zip` file.
3. Run `TheExplorer.exe` (for Windows) or the platform-specific executable.
4. Explore, survive, and uncover the secrets of the alien world!
